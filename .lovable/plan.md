
# מערכת פיננסית משפחתית — MVP (ללא הרשמה)

אפליקציית ווב Mobile-First (React + Tailwind + Vite) בעברית RTL, עם Lovable Cloud לבסיס נתונים וסנכרון בזמן אמת בין שני הטלפונים. ללא מסך הרשמה/התחברות — בכל מסך הוספה פשוט בוחרים מי הזין: **יונתן** או **שירי**. אפשר להתקין כקיצור (Add to Home Screen) משני המכשירים ולעבוד כאפליקציה.

## איך זה עובד בלי הרשמה

- בסיס נתונים אחד משותף לזוג. אין משתמשים, אין סיסמאות.
- בכל תנועה נשמר שדה `entered_by` עם הערך `yonatan` או `shiri` — נבחר בלחיצה אחת במסך ההוספה.
- בכל מכשיר נשמור ב-`localStorage` ברירת מחדל ("אני יונתן" / "אני שירי") כדי שלא צריך לבחור בכל פעם — אבל תמיד אפשר להחליף לפני שמירה.
- סנכרון: ערוץ Realtime של Lovable Cloud על טבלת `transactions` — ברגע שמישהו מוסיף/עורך/מוחק, השני רואה מיד בלי לרענן.

> הערת אבטחה: בלי הרשמה, בסיס הנתונים פתוח לכל מי שיש לו את כתובת האתר. זה בסדר כל עוד לא משתפים את הקישור עם אף אחד. אם בעתיד תרצה שכבת הגנה (קוד PIN משותף, או הרשמה אמיתית) — נוסיף בקלות.

## היקף ה-MVP

1. **תנועות** — הוספה/עריכה/מחיקה מהירה; בכל תנועה: סוג (הכנסה/הוצאה/קבועה/חיסכון/השקעה), סכום, מטבע, קטגוריה, כותרת, הערה, תגיות, תאריך, **מי הזין (יונתן/שירי)**.
2. **קטגוריות ותגיות** — קטגוריות ברירת מחדל לפי המסמך + אפשרות להוסיף; תגיות חופשיות עם השלמה אוטומטית.
3. **דאשבורד חודש נוכחי** — כרטיסי סיכום (הכנסות, הוצאות, חיסכון/השקעות, יתרה פנויה), גרף עוגה לפי קטגוריה, פיד פעולות אחרונות עם שם המזין.
4. **רשימת תנועות** — סינון לפי חודש, קטגוריה, תגית, מזין.
5. **סנכרון Realtime** בין שני המכשירים.
6. **Mobile-first + Add to Home Screen** — manifest פשוט (אייקון, שם, מסך התחלה) כדי שהאפליקציה תיראה כמו אפליקציה מותקנת בשני הפלאפונים. ללא Service Worker (כדי למנוע בעיות cache ושמשהו שמישהו הזין לא יופיע).

## חוויית משתמש

- ניווט תחתון: דאשבורד · תנועות · ➕ הוספה (כפתור מרכזי בולט) · הגדרות.
- מסך הוספה מהירה: מקלדת נומרית גדולה, ברירות מחדל חכמות (תאריך=היום, מטבע אחרון, מזין אחרון).
- צבעים לפי המסמך: 🟢 הכנסה · 🔵 בית · 🔴 שוטף · 🟣 קבועה · 🟡 חיסכון/השקעה.
- RTL מלא, white-space נדיב, אנימציות עדינות.

## סכימת מסד נתונים

```text
categories(id, name, type, color, icon, is_system)
  -- type: income | expense | fixed | savings | investment
tags(id, name)
transactions(id, type, amount, currency,
             fx_rate_to_ils, amount_ils,
             category_id, title, note,
             occurred_at, entered_by,    -- 'yonatan' | 'shiri'
             created_at, updated_at)
transaction_tags(transaction_id, tag_id)
```

- שערי מט"ח היסטוריים נשמרים על כל תנועה (`fx_rate_to_ils`, `amount_ils`) — לא משתנים בדיעבד.
- RLS: מופעל; פוליסי שמתירים read/insert/update/delete ל-`anon` (כי אין משתמשים). אפשר לעבור בעתיד למודל מאובטח יותר.

## מבנה ראוטים

```text
/                      ← דאשבורד (חודש נוכחי)
/transactions          ← רשימת תנועות + פילטרים
/transactions/new      ← מסך הוספה מהירה
/transactions/$id      ← עריכה
/settings              ← קטגוריות, תגיות, בחירת "אני יונתן/שירי" כברירת מחדל
```

## טכני

- Frontend: React + TanStack Router + Tailwind, Mobile-first, RTL.
- Data: TanStack Query + Supabase Realtime subscription על `transactions`; ב-callback של שינוי קוראים ל-`queryClient.invalidateQueries`.
- חישוב "יתרה פנויה" = הכנסות − הוצאות (חיסכון והשקעות לא נחשבים בזבוז, לפי המסמך).

## מה לא נכלל ב-MVP (לשלבים הבאים)

ייבוא בנק + AI · מודול השקעות מלא · מודול טיולים · תנועות מחזוריות · התראות ודוח חודשי במייל · OCR · הצפנה/PIN.

## סדר ביצוע

1. הפעלת Lovable Cloud + סכימה + RLS פתוח + seed קטגוריות.
2. Shell Mobile-first: layout, bottom nav, RTL, פלטת צבעים, manifest להתקנה במסך הבית.
3. מסך הוספה מהירה (כולל בורר יונתן/שירי) + רשימת תנועות + עריכה/מחיקה.
4. דאשבורד עם כרטיסי סיכום וגרף עוגה.
5. Realtime sync + בדיקה משני דפדפנים במקביל.
