
# תכנית שיפורים — גרסה 2

לפני שאני מתחיל, יש כמה נקודות לאישור (ראה "שאלות" בסוף). בינתיים — זו התכנית המלאה.

## 1. פריסה ריספונסיבית: מובייל מול דסקטופ
- היום `MobileLayout` נכפה תמיד. אבנה `AppShell` שמחליט לפי `useIsMobile`:
  - **מובייל (<768px)**: כמו היום — Bottom nav + כפתור + עגול, מסכים בעמודה אחת.
  - **דסקטופ (≥768px)**: סייד-בר ימני (RTL) עם ניווט, כותרת עליונה עם בורר חודש, ותוכן ברוחב מקסימלי (`max-w-6xl`) במרכז. הדאשבורד יוצג ברשת של 2–3 עמודות (סיכומים בעמודה אחת, גרפים בשנייה), רשימת התנועות בטבלה במקום כרטיסיות.
- הטופס יישאר זהה לוגית, רק רחב יותר במסך גדול (`max-w-2xl`).

## 2. מסך תנועה: צפייה לפני עריכה
- היום `/transactions/$id` פותח ישר את הטופס. אפצל:
  - **`/transactions/$id`** = מסך צפייה בלבד (קריאה): סכום, סוג, קטגוריה (עם צבע), תאריך, מי הזין, תגיות, הערה, ושערי מט"ח אם רלוונטי. כפתור **"ערוך"** וכפתור **"מחק"** למעלה.
  - **`/transactions/$id/edit`** = הטופס הקיים.
- כל שורה ברשימת התנועות תוביל למסך הצפייה (לא לעריכה).

## 3. השקעות נחשבות כיציאת כסף
- היום `isCashflowOut` כולל רק `expense` ו-`fixed`. אעדכן ל-`expense | fixed | savings | investment` — כלומר חיסכון והשקעה ייגרעו מהיתרה הפנויה החודשית.
- הדאשבורד יתעדכן: "יתרה פנויה" = הכנסות − (הוצאות + קבועות + חיסכון + השקעה).
- כרטיסי הסיכום יציגו בנפרד: הכנסות / הוצאות שוטפות / קבועות / חיסכון / השקעה.

## 4. ניווט בין חודשים
- בראש הדאשבורד (וגם בראש רשימת התנועות) אוסיף **בורר חודש**: חיצים `‹ נובמבר 2026 ›` + תפריט קפיצה.
- ה-state יישמר ב-URL (`?month=2026-04`) כדי שזה יישמר ברענון ויעבוד גם בסנכרון בין מכשירים.
- כל השאילתות (`fetchTransactionsBetween`) יקבלו את החודש הנבחר במקום החודש הנוכחי בלבד.

## 5. מודול השקעות בסיסי
- אוסיף מסך חדש **`/investments`** (ייכנס לניווט התחתון/סייד-בר במקום "הגדרות" שיעבור לתפריט).
- מודל נתונים: טבלה חדשה `investment_accounts` עם שדות: `name`, `kind` (`money_market` | `interactive` | `other`), `color`, `currency`.
- בכל תנועה מסוג `investment` יתווסף שדה אופציונלי `investment_account_id`. בקטגוריות אזרע ברירות מחדל:
  - "קרן כספית" → חשבון "קרן כספית"
  - "אינטראקטיב" → חשבון "Interactive Brokers"
  - "אחר" → חשבון "השקעות אחרות"
- כשמוסיפים תנועה מסוג השקעה והקטגוריה ידועה — שיוך אוטומטי לחשבון. אפשר גם לבחור ידנית.
- מסך ההשקעות יציג 3 כרטיסים (אחד לכל חשבון) עם סך ההפקדות לאורך זמן + גרף קווי מצטבר.

> הערה: זה עוקב אחרי **תזרים** (כמה הפקדנו), לא שווי שוק עדכני. שווי שוק אמיתי יבוא בשלב מאוחר עם API.

## 6. גרפים — לא רק עוגה
בדאשבורד יוצגו (לפי החודש הנבחר):
1. **גרף עוגה — פילוח הוצאות לפי קטגוריה**, בצבע הקטגוריה (כמו היום אבל עם הפרדה ברורה לכל קטגוריה במקום צבע אחיד).
2. **גרף עמודות — השוואה חודשית**: 6 החודשים האחרונים, עמודה לכל סוג (הכנסה/הוצאה/קבועה/חיסכון/השקעה) עם צבעים תואמים.
3. **גרף עמודות אופקי — Top 5 קטגוריות הוצאה** בחודש, כל עמודה בצבע הקטגוריה שלה.

צבעים: אשתמש ב-`category.color` הקיים בכל גרף שמציג קטגוריות, כך שכל קטגוריה מקבלת גוון ייחודי. צבעי הסוגים יישארו לפי `--income / --expense / --fixed / --savings` (לא יהיה הכל אדום או הכל כחול).

## 7. שינויי DB (migrations)
1. טבלה חדשה `investment_accounts` + GRANT + RLS פתוח (אותו דפוס כמו שאר הטבלאות באפליקציה הזו).
2. עמודה `investment_account_id uuid` ל-`transactions` (nullable, FK רכה).
3. זריעת 3 חשבונות התחלתיים + עדכון/הוספת קטגוריות "קרן כספית" ו"אינטראקטיב" מסוג `investment`.

## 8. סדר ביצוע
1. שינוי `isCashflowOut` + עדכון הדאשבורד (שינוי קטן וקריטי להבנת היתרה).
2. ריספונסיביות: `AppShell` חדש עם הסתעפות מובייל/דסקטופ.
3. בורר חודש + URL state + עדכון שאילתות.
4. מסך צפייה לתנועה + פיצול route עריכה.
5. גרפים נוספים בדאשבורד (עמודות + Top 5) עם צבעי קטגוריה.
6. מיגרציות השקעות + מסך `/investments` + שיוך אוטומטי בטופס.

## שאלות לפני שאני מתחיל
1. **חשבונות השקעה** — אמרת "3 דברים: קרן כספית, אינטראקטיב, ו...?" השלישי שאני מציע הוא "השקעות אחרות" (גמיש). מתאים, או שיש שם ספציפי שאתה רוצה (למשל "פנסיה", "קריפטו", "חסכון ילדים")?
2. **חיסכון לעומת השקעה** — שניהם יורדים מהיתרה הפנויה? (אמרת בפירוש על השקעה. רוצה שגם חיסכון יתנהג ככה? לדעתי כן, לאותו רציונל.)
3. **דסקטופ** — סייד-בר ימני קבוע, או טופ-בר אופקי בלבד? אני מציע סייד-בר ימני (טבעי יותר ב-RTL).
